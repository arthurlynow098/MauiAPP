# MauiAPP

## Sobre o projeto

Atividade acadêmica em C# e .NET MAUI, com projetos para Android e Windows e destino .NET 9.

## Como explorar

Abra `MauiApp2.sln` em um ambiente com SDK .NET 9 e as cargas de trabalho MAUI para a plataforma desejada. Escolha o projeto Android ou WinUI como destino.
